# 🤖 Telegram Bot Portfolio

Production-ready Telegram bots in Python, each running 24/7 with a **live demo you can try right now**.

| Bot | What it does | Live demo |
|---|---|---|
| [🛟 Support Assistant](support-bot/) | FAQ answers from buttons or free text, one-tap hand-off to a human agent, tickets and ratings | [@ariahelp_demo_bot](https://t.me/ariahelp_demo_bot) |
| [📅 Booking Assistant](booking-bot/) | Appointment booking with free-slot search, reminders and owner notifications | [@ariabook_demo_bot](https://t.me/ariabook_demo_bot) |
| [🪙 Crypto Price Alert](crypto-alert-bot/) | Price alerts, watchlist and a daily market report | [@aria_pricewatch_bot](https://t.me/aria_pricewatch_bot) |

**Stack:** Python 3 · python-telegram-bot 21 · SQLite · REST APIs · Linux / systemd

Every bot is configured with environment variables (see each folder's `.env.example`), keeps its data in SQLite, and never logs its token.
